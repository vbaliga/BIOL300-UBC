# Materials for BIOL 300 UBC
Content herein is based on materials created by Whitlock & Schluter (https://whitlockschluter3e.zoology.ubc.ca/index.html). Key changes have amounted to a "UBC Edition" of the R labs. 

Instructors and students at UBC should use the UBC Edition https://vbaliga.github.io/BIOL300-UBC/ for BIOL 300 instead of the original site. 

Comments and suggestions are greatly appreciated. If something is not working or can be improved, please let us know. Please e-mail Vikram Baliga at vikram.baliga@ubc.ca with any thoughts you have about how these tutorials can be improved.
